ひとつずつ TODOについて

プライバシーポリシー

更新日：2026年9月9日

扱うデータと利用目的

ひとつずつ TODOは、タスク名、メモ、締切、状態、子タスク、操作履歴などを端末内に保存するTODOアプリです。Google Driveとの連携は任意です。連携時にはGoogleアカウントの識別情報とメールアドレスを取得し、連携先の表示と、異なるアカウントへの誤った同期の防止に利用します。

保存先と同期

タスクと同期記録、連携先の識別情報は利用中のブラウザの保存領域に保存します。Google Drive連携を有効にすると、タスク・子タスク・履歴・削除記録を、ご本人のGoogle Driveのアプリ専用データ領域に保存し、同じGoogleアカウントで連携した端末間の同期に利用します。通常のDriveファイル全体へのアクセスは要求しません。変更の衝突を解決するため、同期記録には過去のタスク内容が含まれる場合があります。

認証と第三者サービス

Googleの認証画面で利用者が許可した範囲でのみアクセスします。アクセストークンは実行中のメモリで扱い、ブラウザの永続保存領域やエクスポートファイルには保存しません。アプリの配信にはGitHub Pages、認証と同期にはGoogleのサービスを利用します。通信に必要なIPアドレスなどは各サービスによって処理され、各社のポリシーが適用されます。タスク内容をGitHubのリポジトリや運営者のサーバーに送信する機能はありません。

データの利用・共有

Googleから取得するデータは、利用者向けのアカウント識別と同期機能の提供にのみ利用します。販売、広告配信、信用評価、汎用AIモデルの学習には利用しません。本アプリによるGoogle APIから取得した情報の利用と他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

保存期間と削除

端末内データは、利用者がブラウザのサイトデータを削除するまで保持されます。ただしブラウザの管理によって削除される場合もあります。タスクを削除しても、同期の変更記録には過去の内容が残る場合があります。Drive上の同期記録は自動削除しません。Google Driveの設定にあるアプリの管理から本アプリの非表示のアプリデータを削除できます。

同期を停止しても保存済みデータは削除されません。利用を終了して全データを削除する場合は、すべての端末で同期を停止し、Googleアカウントで本アプリへのアクセス権を取り消したうえで、Drive上のアプリデータ、各ブラウザのサイトデータ、ご自身で書き出したJSONファイルを削除してください。端末に残ったデータで再接続すると、再度アップロードされる場合があります。
