# ひとつずつ — TODO

**[アプリを開く](https://l3ickey.github.io/hitotsu-todo/)**

質問に答えて優先順位を決め、ひとつずつ作業するTODOアプリです。タスクは利用する端末内に保存されます。任意のFirebase連携を有効にすると、許可された同じGoogleアカウントの端末間でタスクを自動同期できます。保存先は運営者が管理するFirebaseで、運営者は内容にアクセスできます。タスクはGitHubには送信しません。

「データの持ち運び → Firebase同期」から、保存先の説明に同意してGoogleでログインします。ログインは端末のブラウザに保存され、再起動後も復元します。データ消去・ログアウト等では再認証が必要です。親子セットの変更が衝突した場合は、残す内容を選択します。オフライン中の変更は端末内に残り、再接続後に同期します。「今やる」の固定は端末ごとです。JSONでの退避も引き続き利用できます。

- 優先度1：自分が渡すまで相手の作業が止まる
- 優先度2：10分以内に終わる
- 優先度3：3日以上かかる
- 優先度4：それ以外。締切順に並ぶ

最初にYesになった条件で判定します。すべての優先度で任意の締切と子タスクを設定できます。同順位は締切順・登録順。子タスクは手動で並べ替えます。


## iPhone

Safariで上記のアプリを開き、共有メニューから「ホーム画面に追加」。ホーム画面から起動し、「データの持ち運び」で「オフライン利用の準備完了」を確認してください。必要なファイルが保存された後は、オフラインでも使えます。

## PC・別のPCへの持ち運び

このリポジトリの Code → Download ZIP を選び、展開して `index.html` を開いてください。アプリのインストールは不要です。Firebase同期はHTTPSまたはlocalhostが必要です。ローカルHTMLでは端末内保存とJSONの持ち運びを利用してください。

データはHTMLに書き戻されません。**移動前に「データの持ち運び」からJSONを書き出し、移動先で読み込んでください。** インポートは現在の一覧の置き換えです。ブラウザの保存データ消去や保存容量の不足に備え、定期的にJSONを別途保存してください。file URLのブラウザ保存は仕様上保証されないため、PC版でもJSONのバックアップを推奨します。

## タスクの操作

子タスクは初期状態と追加後には折りたたまれます。「ステップ ○件」をタップするとツリー表示で展開し、もう一度タップすると閉じます。開いた状態はその画面を使っている間は維持され、アプリを開き直すと折りたたまれます。

タスク名やメモの冒頭をタップして名前・メモ・締切を編集し、変更は自動保存されます。優先度は維持され、必要な場合だけ質問に答え直せます。同じ編集画面で状態変更・子タスク追加・複製・登録日と履歴の確認ができます。「今やる」で1件固定。「待ち」は通常の候補から分離。未完了の子がある親は完了できません。子を再開すると完了した親も再開します。出戻りは「再開」、新たな同じ作業は「複製」を使います。

登録したタスクやエクスポートJSONを、この公開リポジトリにアップロードしないでください。アプリの公開とタスクの保存先は別です。

## 更新

アプリ本体は `index.html` にCSSとJavaScriptを同梱しています。同期用の `firebase-sdk.js` も同じフォルダーに配置してください。更新時は `sw.js` のキャッシュ版番号も変更してください。オンライン時に新しい版を取得し、画面の「更新する」で反映します。
